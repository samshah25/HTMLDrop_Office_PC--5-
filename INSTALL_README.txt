HTML Drop update - 28 Oct 2026

What is inside: only the program files. No data, no passwords, no dashboards.

HOW TO INSTALL ON THE OFFICE PC
1. Open the HTML Drop folder on the office PC (the one with server.py and the "data" folder).
2. Optional but recommended: copy server.py, Master_dashboard.html and portal.html somewhere as a backup.
3. Extract this zip INTO that folder and choose "Replace the files in the destination".
4. Double-click restart.bat. It should say "HTML Drop is running".
5. Open http://<office-pc>:8150/Master_dashboard.html and press Ctrl+F5.

Not included on purpose (the PC keeps its own):
- data\ (uploaded pages, users, logins)   - DynamicProjects\ (dynamic dashboards)
- config.json (port, admin password)       - logs\

The first time, dashboard pictures take a few minutes to appear; until then cards show their icon.
