Reseller Performance Program

A performance-based program for Justdial reseller agencies. Every agency follows the same 45-day journey: train, assess its market, then close at least 3 deals. An agency that misses the target gets 10 days to recover. If it still misses, it is closed out of the program over the next 15 days.

How it works

Deals and commission

Agencies sell two products. Both count toward the same target of at least 3 deals. Use the tracker at the bottom of this page to check any agency.

Package

1 package = 1 deal

Each package sold counts as one full deal. Average package value is about ₹26,000.

JDRR

3 JDRR = 1 deal

Every 3 JDRR sales count as one deal. 1 or 2 JDRR sales left over carry forward until the third is sold.

Ways to reach at least 3 deals

PackagesJDRR salesDealsTarget

What counts as a deal

  • Payment is realised, not just booked. The deal date is the payment date.
  • Closed by a trained seller of the agency, using that seller's own login.
  • Closed on or after Day 8. Deals from the market assessment count.

Commission

Rate

Flat %

The same rate on every package and JDRR sale, for every agency, from the first deal.

How it works

Tracking

Each agency is reviewed regularly from Day 1, so a slow agency is spotted early. Tracking gets closer once an agency is on warning.

Staying on track

The agency should reach these totals by each date during the performance window. Missing one triggers an extra RM call, not a penalty.

What is tracked for every agency

Results

  • Packages sold
  • JDRR sold
  • Total deals (packages + JDRR ÷ 3)
  • Collection

Activity

  • Leads worked
  • Meetings and demos held
  • Open pipeline
  • Days since the last deal

Weekly leaderboard

All agencies are ranked by deals closed, and the ranking is shared every week so agencies can see how they compare. Agencies on warning are flagged privately, not on the shared board.

Rules

Rule book

Every rule of the program, grouped in the order an agency meets them. Each rule has an ID (for example, F2) so it can be quoted in notices and agreements. The same rules apply to every agency.
